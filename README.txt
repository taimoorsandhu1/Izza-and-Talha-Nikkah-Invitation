Wedding Invitation Website Package

1. Open index.html in a browser to preview the invitation.
2. The supplied HTML references local media files that were not included in the uploaded text file. Add the original files beside index.html using the exact filenames below for the complete appearance/functionality.
3. The page also loads Google Fonts, Tailwind CSS, Phosphor Icons, and some remote images from the internet, so an internet connection is needed for those resources.
4. To publish, upload the folder contents to GitHub Pages, Netlify, Vercel, or another static host.
